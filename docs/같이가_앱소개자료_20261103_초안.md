# 같이가 앱 소개 자료 초안

작성일: 2026-11-03

> 이 문서는 11월 3일에 작성한 초기 제출 초안입니다. 이후 논의에서 지도 중심 구성을 재검토하고, 주행 중 떨어져 있는 차량 사이의 유대감을 만드는 대표 기능을 탐색하고 있습니다. 현재 후보와 검증 상태는 [2026-11-04 기획 방향](기획_방향_20261104.md)을 참고하세요. 이 초안을 최종 제출 문안으로 사용하기 전에는 최신 방향에 맞춰 수정해야 합니다.

접수번호: 미기재

앱명 / 프로젝트명: 같이가

## 1. 앱 한 줄 소개

같이가는 여러 대의 차로 떠나는 친구들이 차량의 이동·주행 상태를 바탕으로 서로의 상황을 이해하고, 대화와 휴식·합류를 함께 조율하며 가는 길부터 하나의 여행을 즐기는 Pleos Connect 기반 동행 앱입니다.

## 2. 기획 배경

친구들과 여러 대의 차량으로 여행을 떠나면 목적지는 같아도 이동 경험은 차량별로 나뉩니다. 같은 차에 탄 사람끼리는 대화가 이어지지만 다른 차량의 친구들과는 “어디쯤 왔어?”, “잠깐 쉬었다 갈까?”, “주차는 어디에 해?”라는 질문을 전화나 단체 채팅으로 반복하게 됩니다. 운전자는 메시지를 바로 확인하기 어렵고, 동승자가 없는 차량에서는 이동 중 의견을 전달하기가 더욱 번거롭습니다.

휴식이나 충전이 필요한 시점, 도착 예정 시간도 차량마다 다릅니다. 이러한 차이를 제때 알지 못하면 일행이 서로 다른 곳에 정차하거나, 먼저 도착한 사람이 뒤 차량을 기다리며 계속 연락해야 합니다. 여행을 함께 계획했지만 가는 길은 각자 움직이게 되는 것입니다.

같이가는 이 이동 구간에 주목했습니다. 차량의 위치·내비게이션 정보와 지원되는 주행·에너지 데이터를 동행 상황에 연결하고, 음성과 짧은 선택으로 의사를 나누도록 설계합니다. 이를 통해 친구들이 차를 나눠 타더라도 서로를 재촉하지 않고, 출발부터 합류까지 함께 여행한다는 경험을 만들고자 합니다.

## 3. 앱 주요 기능 및 차량 특화 요소

### ① 같은 목적지를 향해 가는 동행 지도

주행 홈에서는 우리 차와 동행 차량이 공동 목적지를 향해 이동하는 모습을 간결하게 표시합니다. 차량별 도착 예정과 상세 상태는 별도의 ‘일행’ 화면에서 확인하도록 구성해, 홈에 정보가 과도하게 쌓이지 않도록 합니다. 위치 갱신이 늦어지면 마지막 수신 시간을 표시하고 현재 상태와 구분합니다.

### ② 차량 상태를 참고하는 공동 휴식

지원 차량의 트립 주행 시간과 배터리·연료 잔량을 조회해, 사용자가 휴식이나 에너지 보충 필요성을 확인하고 일행에게 공동 정차를 제안할 수 있도록 합니다. 제안은 음성 또는 짧은 선택지로 응답하며, 합의된 장소와 휴식 계획을 일행이 함께 확인합니다. 차량마다 다른 필요를 하나의 여행 일정에 반영하는 것이 핵심입니다.

### ③ 동의를 바탕으로 한 차량 간 대화

다른 차량에 대화를 요청하고 상대가 수락하면 연결하는 음성 소통을 계획합니다. ‘우리끼리 모드’에서는 차량 간 음성 공유를 잠시 중단하고, 차 안에서의 개인적인 시간을 보낼 수 있습니다. 음성 연결 상태와 전달 대상을 명확하게 표시하며, 위치 공유와 음성 공유는 구분해 설정합니다.

### ④ 먼저 도착한 일행과의 합류

먼저 도착한 친구가 주차 위치나 만날 장소에 관한 짧은 정보를 전달하면, 이동 중인 일행이 음성으로 확인하도록 합니다. 공통 목적지·경유지와 내비게이션 정보를 연결해 차량별 이동 상황을 이해하고 합류를 돕습니다. 목적지나 경유지 변경은 사용자 확인을 거쳐 요청하도록 설계합니다.

차량 특화 요소는 차량에서 직접 제공하는 주행·에너지 데이터, 내비게이션 정보, 차량 오디오와 주행 중 사용 제한을 동행 기능에 연결하는 데 있습니다. 지도·통신 등 외부 기술은 이를 구현하는 보조 수단으로 활용합니다.

## 4. 주요 사용 시나리오

친구 여섯 명이 차량 세 대로 서울에서 강릉으로 주말 여행을 떠납니다.

1. **출발 전:** 각 차량이 같은 여행에 참여하고 공동 목적지를 확인합니다. 참여자는 위치와 음성 등 공유할 정보와 대상을 확인한 뒤 동의합니다.
2. **이동 중:** 주행 홈에서 세 차량이 목적지를 향해 가는 모습을 확인합니다. 친구와 이야기하고 싶을 때 대화를 요청하고, 상대가 수락하면 연결합니다.
3. **휴식 조율:** 한 차량에서 지원되는 주행 시간이나 배터리 잔량을 확인한 뒤 휴식을 제안합니다. 다른 차량은 허용된 입력 방식으로 짧게 응답하고, 합의한 만남 장소와 휴식 계획을 확인합니다.
4. **개인적인 시간:** 차 안 친구와 따로 이야기하고 싶으면 ‘우리끼리 모드’를 선택해 차량 간 음성 공유를 쉬어갑니다.
5. **도착·합류:** 먼저 도착한 친구가 “입구 오른쪽에 빈자리가 있어”라는 소식을 전달합니다. 뒤따라오는 일행은 이를 음성으로 확인하고 약속한 장소에서 합류합니다.

주행 중 기능은 해당 앱 카테고리와 플랫폼의 주행 규제가 허용하는 범위에서 제공하며, 설정과 복잡한 입력은 정차 상태에서 수행하도록 합니다.

## 5. 개발 계획

Pleos Connect에서 실행되는 Kotlin·Jetpack Compose 기반 Android Automotive 앱으로 개발합니다. 기존 공식 샘플은 유지하고 별도 모듈에서 기능을 검증합니다. 화면은 ‘주행·일행·대화·쉬기’로 구분하고, 제공받은 Pleos Connect 2.1.5 디자인 리소스를 기준으로 실제 앱 창 크기에 대응하도록 구현합니다.

| SDK / API | 구체적인 활용 계획 |
|---|---|
| Vehicle SDK 2.3.2 — Odometer | `getTripCurrentDrivingTime()` 등으로 트립 주행 시간을 조회해 휴식 제안의 참고 정보로 활용합니다. 기능별 capability를 먼저 확인하고 지원되는 항목만 사용합니다. |
| Vehicle SDK 2.3.2 — EvBattery / Fuel | `getEvBatteryStateOfCharge()`, `getFuelPercent()`로 지원 차량의 에너지 상태를 확인하고, 충전·주유를 고려한 공동 정차 조율에 활용합니다. 공유 여부는 사용자 선택에 따릅니다. |
| NaviHelper SDK 3.0.5 | `getCurrentLocationInfo()`, `getDestinationInfo()`, `getWaypointInfo()`로 차량의 현재 위치와 목적지·경유지 정보를 조회합니다. 목적지·경유지 변경은 사용자 확인 후 `requestRoute()`·`addWaypoint()` 등으로 기본 내비게이션에 요청하고 처리 결과를 확인합니다. |
| SpeechToText / TextToSpeech SDK | 공식 문서의 사용 조건과 기기 지원 여부를 확인한 뒤 짧은 음성 응답 인식과 소식 읽어주기를 구현합니다. 인식 결과를 투표·응답에 연결하는 앱 로직은 별도로 개발합니다. |
| AAOS `CarUxRestrictionsManager` 및 오디오 포커스 | 플랫폼의 주행 규제 상태에 따라 기능을 축소·비활성화하고, 음성 사용 시 오디오 포커스 요청과 상실 처리를 구현합니다. 주행 중 사용을 위해 앱 카테고리, DO 선언 요건 및 기능별 제한을 검토·검증합니다. |

개발은 **차량 데이터 조회 검증 → 주행 지도와 일행 상태 표시 → 휴식 제안·응답 → 음성 입출력 및 통신 → 통합 테스트** 순으로 진행합니다. 초기 단계는 서버에 위치를 올리지 않는 로컬 시뮬레이션으로 여러 차량의 이동과 오류 상황을 검증합니다. 실제 차량 간 위치·응답 동기화와 음성 통화는 별도의 통신 개발 범위로 구분합니다. 음성 인식·합성 SDK가 차량 간 통화를 제공한다고 가정하지 않습니다.

현재 초기 프로토타입에는 배터리 충전율과 내비게이션 현재 위치의 조회 성공 기록이 있으며, 지도와 로컬 동행 차량 시연을 구현했습니다. 트립 주행 시간 등 일부 속성은 현재 에뮬레이터에서 미지원으로 확인되어, 지원 환경을 추가 검증한 뒤 적용할 계획입니다. 실제 동행 차량 연결, 음성 통화, 음성 응답 및 휴식 투표는 후속 개발 대상입니다.

Pleos 에뮬레이터에서 창 크기·주야간 모드·주행 규제·조회 실패·위치 갱신 지연·연결 중단 상황을 테스트합니다. 실제 데이터와 시연 데이터는 명확하게 구분하며, 미지원과 조회 실패를 임의의 정상 값으로 대체하지 않습니다. 위치·음성 공유 동의와 종료 절차, 최소 권한, 개인정보 보호를 반영하고 최종적으로 실행 가능한 release APK를 준비합니다.
