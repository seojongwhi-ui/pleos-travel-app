# 같이가 기획 방향과 대표 기능 후보

작성일: 2026-11-04

상태: 팀 논의용 탐색안. 아래 후보 중 대표 기능은 아직 확정되지 않았습니다.

## 풀려는 문제

여러 대의 차로 함께 여행을 떠나면 목적지는 같아도 차 안에서 생기는 대화, 웃음, 풍경, 쉬고 싶은 마음은 차량마다 따로 남습니다. 운전 중에는 단체 채팅이나 잦은 전화로 그 순간을 이어 가기도 어렵습니다. 앱의 목표는 **출발부터 헤어질 때까지, 서로 다른 차에 있어도 한 여행을 함께하고 있다는 감정**을 만드는 것입니다.

기획 문장 후보: **“차는 여러 대, 여행은 하나.”** 앱명 ‘같이가’는 가칭입니다. 지도에서 차량 위치를 함께 보여 주는 것은 보조 표현입니다. 한 화면에 많은 상태 정보를 쌓거나 일반적인 미션·배지·속도 경쟁을 중심에 두지 않습니다.

## 대표 기능을 고르는 기준

각 후보는 단독으로 앱을 설명할 수 있어야 합니다. 휴대전화의 통화·채팅·투표를 차량 화면에 옮긴 정도라면 차별성이 약합니다. **차량별 이동 위치·목적지·주행 상태가 친구들 사이의 새로운 순간을 만들어야** 합니다. 사람의 감정이나 피로는 차량 값만으로 단정하지 않고, 본인이 직접 표현하게 합니다.

| 독립 후보 | 주행 중 경험 | 차량 특화성 및 검증할 점 |
|---|---|---|
| **두드리기** | 다른 차에 “똑똑” 하고 말을 걸면 상대 차가 수락한 뒤 짧은 음성 무전을 주고받습니다. | ‘차 안의 일행’을 하나의 대화 상대로 다룹니다. 단순 음성 통화와의 차별점, 운전자 조작 허용 범위를 더 설계해야 합니다. |
| **길 위의 메아리** | 앞서 간 차가 특정 길목에 목소리를 남기면 뒤차가 같은 곳을 지날 때 듣습니다. | 실제 위치와 경로가 메시지 전달 시점을 결정합니다. 위치 오차와 다른 경로로 갈 때의 동작을 검증해야 합니다. |
| **같은 진도, 다른 차** | 차마다 다른 길을 달려도 목적지까지 절반쯤 왔을 때 각 차의 한마디를 듣습니다. | 같은 좌표가 아닌 차량별 여정 진행 정도로 순간을 맞춥니다. 목적지 정보가 없거나 바뀌면 기능을 멈추거나 다시 계산해야 합니다. |
| **나란히 신호** | 떨어져 달리던 일행의 차가 가까워졌을 때 짧은 인사를 제안합니다. | 양쪽 차량 위치의 변화를 대화 계기로 사용합니다. 상대 위치 공유 동의와 업데이트 지연 표시가 필요합니다. |
| **같이 멈춘 순간** | 서로 다른 휴게소에 있어도 일행의 차들이 정차한 순간 짧은 대화를 제안합니다. | 차량의 정차 상태가 만남의 조건입니다. 실제 지원 신호와 주행 제한 정책을 확인해야 합니다. |
| **함께 쉬기** | 한 차가 쉬고 싶다고 말하면 차마다 짧게 응답하고 공동 정차를 결정합니다. | 지원 차량의 주행 시간·배터리·연료 정보가 제안의 맥락을 설명합니다. 정보 공유는 선택 사항입니다. |
| **차 대 차 투표** | “다음에 같이 쉴까?”라는 물음에 사람 대신 차마다 한 표를 냅니다. | 일행의 단위가 차량입니다. 실제 이동 맥락과 연결하지 못하면 일반 투표와 차이가 적습니다. |
| **동행 주파수** | 서로 수락한 차량의 차 안을 잠시 음성으로 연결합니다. | 여러 사람이 함께 듣는 차량 오디오 경험입니다. 일반 그룹 통화와의 차별성 및 오디오 포커스 처리가 과제입니다. |

현재 가장 차량 특화성이 뚜렷한 후보는 **길 위의 메아리**와 **같은 진도, 다른 차**로 보입니다. **두드리기**는 감정적으로 직관적이지만 독립 대표 기능이 되려면 차량 이동과의 결합이 더 필요합니다. 이 평가는 제안이며 팀의 결정이 아닙니다.

## 공개 API와 현재 구현 상태

- [공모전 FAQ](https://appdevchallenge.auto-hmg.io/faq)는 Vehicle, NaviHelper, TextToSpeech, SpeechToText, FusedLocation SDK를 사용 가능 SDK로 안내합니다.
- [Vehicle SDK 2.3.2](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/Vehicle/intro)의 Odometer, EvBattery, Fuel 도메인에서 트립 주행 시간·거리, 배터리 잔량, 연료량 조회를 검토합니다. 기능별 capability와 권한 확인이 선행되어야 합니다.
- [NaviHelper SDK 3.0.5](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/NaviHelper/intro)는 현재 위치·목적지·경유지 정보를 조회하고 기본 내비게이션에 경로 요청을 전달할 수 있습니다. [FusedLocation SDK](https://document.pleos.ai/en/docs/pleos-only/connect-sdk-pleos/FusedLocation/intro)는 지원 환경에서 위치 갱신과 근접 알림을 제공합니다.
- SpeechToText는 음성을 문자로 바꾸고 TextToSpeech는 문자를 읽습니다. 원본 음성 녹음·차량 간 음성 또는 투표 전달은 별도 앱 기능과 통신이 필요합니다.
- 현재 `:travel-preview`에는 우리 차의 배터리 충전율과 내비게이션 현재 위치 조회, 로컬 시뮬레이션 차량을 표시하는 지도 시연이 있습니다. 현재 에뮬레이터에서 트립 주행 시간·거리·연료 조회는 미지원으로 확인됐습니다. 위 표의 차량 간 기능은 **아직 구현되지 않았습니다.**
- [Pleos 주행 안전 가이드](https://document.pleos.ai/docs/pleos-only/vehicle-app-planning-guide/driver-distraction-guideline)에 따라 운전자에게 긴 문장 읽기·입력을 요구하지 않습니다. 실제 허용 범위는 앱 카테고리, DO 선언, 지역과 `CarUxRestrictions` 상태에 따라 검증해야 합니다.

## 사진과 음성 아이디어의 범위

현대차 [빌트인 캠 설명서](https://ownersmanual.hyundai.com/full_webhelp/CE1/2024/ko_KR/idf353f1bbc70.html)는 전용 스마트폰 앱을 통한 저장 영상 다운로드·공유를 안내합니다. 그러나 공개 Pleos SDK에서 제3자 앱이 빌트인 캠의 이미지·영상을 직접 가져오는 API는 확인되지 않았습니다. 지금은 **사용자가 직접 가져온 사진에 음성을 붙이는 후속 기능**으로만 고려하고, 주행 중 블랙박스 자동 촬영·전송을 구현 가능한 핵심 기능으로 적지 않습니다.

## 기존 시각 자료

`docs/design/concepts/20261102/`의 와이어프레임 10장과 퍼소나 보드는 지도·대화·휴식 중심의 **초기 탐색 자료**입니다. Pleos 2.1.5 시스템 영역을 화면에 표현했지만, 생성 이미지의 세부 규격이나 주행 중 사용 허용 여부가 검증된 최종 디자인은 아닙니다. 대표 기능을 선택하면 해당 경험을 중심으로 다시 설계합니다.
